# Atividade 01 - Machine Learning

**1. Explique, com suas palavras, o que é machine learning?**

Machine Learning é uma área da Inteligência Artificial que permite que os computadores aprendam com os dados. Em vez de programar todas as regras, o computador analisa exemplos e consegue fazer previsões ou tomar decisões com base no que aprendeu.

**2. Explique o conceito de conjunto de treinamento, conjunto de validação e conjunto de teste em machine learning.**

O conjunto de treinamento é usado para ensinar o modelo. É com esses dados que ele aprende.

O conjunto de validação é usado para verificar se o modelo está aprendendo corretamente e para fazer ajustes, se necessário.

O conjunto de teste é usado no final para avaliar o desempenho do modelo com dados que ele nunca viu antes.

**3. Explique como você lidaria com dados ausentes em um conjunto de dados de treinamento.**

Primeiro eu verificaria quantos dados estão faltando. Se forem poucos, eles podem ser removidos. Se forem importantes, eu poderia preencher os valores usando a média, a mediana ou o valor mais frequente, dependendo do tipo de dado.

**4. O que é uma matriz de confusão e como ela é usada para avaliar o desempenho de um modelo preditivo?**

A matriz de confusão é uma tabela que mostra quantos resultados o modelo acertou e quantos ele errou. Ela ajuda a entender se o modelo está fazendo boas previsões e onde ele está cometendo erros.

**5. Em quais áreas você acha mais interessante aplicar algoritmos de machine learning?**

A área que eu acho mais interessante é a saúde, porque o machine learning pode ajudar na análise de exames, na previsão de doenças e no apoio aos profissionais de saúde. Também acho interessante o uso na agricultura para melhorar a produção e na indústria para identificar problemas nas máquinas antes que elas parem de funcionar.
